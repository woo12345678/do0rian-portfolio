01 · CAMPAIGN

매번 다른 밤을 한 땀씩 잇는다.

12밤 캠페인은 물질적으로 구별되는 24개의 저작 포인트 클라우드(point-cloud) 패턴 청사진을 사용합니다. 각 청사진은 seeded mirror, rotation, jitter, order variations—시드 기반 미러·회전·지터·순서 변형—으로 다시 구성되어 반복 플레이에도 경로의 성격을 유지하면서 새로운 지도를 만듭니다.

01 / DIFFICULTY

다섯 가지 밤의 강도

다정한 밤, 보통, 거친, 지옥, 불가능 중 하나를 선택합니다. 난이도마다 잉크 나방(moth)의 속도(speed), 가속(acceleration), 반응(reaction)이 함께 스케일링됩니다. 지옥/불가능(Hell/Impossible)은 의도적으로 극단적(intentionally extreme)이지만, 승패 가능성을 단정하지 않습니다.

02 / SYSTEM

경로 기반 스티치

선분 거리 판정과 경로 충돌을 정교한 라인 드로잉 규칙으로 바꿉니다. 빛나는 골무 파동으로 가까운 나방을 밀어내며 끊어지기 전에 밤을 봉합합니다.

03 / VISUALS

Authored procedural visuals

고정 1280×720 Canvas 2D 세계에 직접 그린 회화적 질감과 반응형 고해상도 렌더링을 결합했습니다.

02 · SCREEN

난이도를 고르고 밤으로 들어간다.

03 · SCOPE

검증된 정적 릴리스

STITCHKEEPER 2.0.0 정적 싱글 플레이어 에디션입니다. 키보드·마우스·터치 입력과 합성 Web Audio를 지원하며, canonical source suite의 Node 서브테스트 15/15와 Chromium smoke를 통과했습니다.
